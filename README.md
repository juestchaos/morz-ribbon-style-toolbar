# morz-ribbon-style-toolbar

Morz 编辑器的 Ribbon 风格格式工具栏插件。

把单行格式栏重排为两行分组 Ribbon：原生 **25 项**全部保留，另把藏在菜单里的 **正文**、**下划线** 提升为一级按钮，共 **27 个按钮**。

**启用即接管**：挂载后自动隐藏原生格式栏，编辑器顶部只留一条 Ribbon；关掉插件原生栏自动恢复。

## 组内排布

行优先，每组每行 2 个（列数 = ⌈项数 / 2⌉），所以同组内语义相邻的两项始终并排，不会出现上下错开：

| 组 | 第一行 | 第二行 |
|---|---|---|
| 编辑 | 撤销、重做 | 清除格式 |
| 标题 | H2、H3 | 标题▾、正文 |
| 字符 | 加粗、斜体、下划线 | 高亮、注释、格式▾ |
| 段落 | 无序、有序、任务 | 引用、Callout |
| 插入 | 表格、图片、目录 | YAML、表情、代码块 |
| 视图 | 专注模式、全屏 | 阅读模式 |

## 安装

**插件市场**：Morz → 设置 → 第三方插件 → 市场 → 搜索「Ribbon 工具栏」。

**手动**：把 `manifest.json`、`main.js`、`icon.svg` 放进 `%APPDATA%\com.morz.editor\plugins\morz-ribbon\`，再到设置 → 第三方插件 → **刷新** → 启用。
目录不对时：设置 → 第三方插件 → 「打开目录」，把本文件夹复制进去后刷新。

## 行为

| 项 | 说明 |
|---|---|
| 挂载位置 | `ctx.ui.floatingHost`（回退 `.editor-pane`），`position:sticky` 贴在编辑区顶部；切换文档时若宿主换了面板会跟随 |
| 重复挂载 | 幂等：挂载前清掉历史 `.mzr-ribbon` 与旧样式，热重载不会叠出两条 |
| 折叠 | 右下角箭头或命令面板「Ribbon：折叠 / 展开」，41px 与原生栏等高；空间不足时该行横向滚动，折叠箭头固定不滚动 |
| 生效范围 | 仅 Markdown 文档视图。判据为 `ctx.views.active().kind === "editor"` 且路径以 `.md` / `.markdown` / `.mdx` 结尾；空白页、附件、插件视图不显示 Ribbon，原生栏同时恢复 |
| 隐藏原生栏 | 默认开启，整槽隐藏 `.toolbar-top-slot`（41px 一并回收，不留空白）；设置里可关掉改成双栏并存 |
| 弹层 | 标题▾（7 项）、格式▾（9 项）、表情（46 个）、整组折叠（按组动态）均为插件自绘，`position:fixed` 自动避让边界 |

## 命令映射（27 项）

| 类别 | 数量 | 实现 |
|---|---|---|
| 直通 `ctx.editor.runCommand` | 21 | 清除格式、H2/H3、标题菜单、正文、加粗、斜体、下划线、高亮、注释、格式菜单 9 项、列表×3、引用、Callout、表格、目录、YAML、代码块、全屏 |
| 自建 / 近似 | 4 | 撤销、重做（SDK 未暴露 history，转发快捷键）、本地图片（`input[type=file]` + `vault.writeBlob`）、表情（内置面板） |
| 缺口 | 2 | 专注模式、阅读模式——宿主内建，插件无公开接口，点击给出明确提示 |

## 已知限制

- 行内格式的「激活态」为近似判断（依据光标邻近文本标记），不是语法树精确解析
- 「正文」（降为段落）依赖 `setHeading(0)`，SDK 未文档化，失败时会提示
- 隐藏原生栏依赖 `.toolbar-top-slot` / `.toolbar-top` 类名，属于文档未承诺的内部结构，宿主改版后可能失效
- 撤销/重做依赖向编辑器派发 `Ctrl/Cmd+Z`，非官方命令通道
- 分屏时只挂一条 Ribbon，非活动面板不再有自己的工具栏

## 权限

| 权限 | 用途 |
|---|---|
| `workspace` | 挂载 Ribbon 到编辑区，隐藏原生格式栏 |
| `editor:insert` | `runCommand` 派发全部格式命令 |
| `editor:direct` | 读取选区与光标状态，显示按钮激活态 |
| `settings` | 保存「隐藏原生格式栏」等开关 |
| `vault:write` | 本地图片写入 `assets/` |
